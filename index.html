What this file demonstrates

This is an interactive companion demo, not a bundled Python server. Appointment screens reuse the uploaded Nuvora HTML. Restaurant and hospitality logic is recreated in browser JavaScript from the documented branch capabilities. Backend authorization, tenant isolation, database transactions, HTTP security, and concurrency cannot be demonstrated by this single-file application.
